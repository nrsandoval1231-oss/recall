# Organized note body editor

Generated notes store their native identity and properties in YAML; the current correction textarea sends plain replacement words without that header and native validation refuses them. Separate body editing from the existing properties in the webview. Preserve the exact original header and separator when building a correction; pass the complete document through the unchanged native optimistic-revision/receipt writer. Legacy plain notes stay unchanged. Never reinterpret foreign identity headers; malformed native properties require review. Show readable body text in existing board/evidence/answer/history views while retaining full properties in Obsidian and native history. Verify metadata preservation, raw notes, malformed headers, explicit plain correction payload, stale-write protections and existing async editor regressions. No native guard weakening or new visual module.
