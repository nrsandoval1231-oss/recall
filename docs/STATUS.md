**2026-10-22 cloud conflict review:** a 409 from the cloud no longer strands the memory. Cloud settings now lists each conflicted memory with your edit and the current cloud version; you choose Keep my edit, Use cloud version (confirmed, since it discards the local edit) or Save combined text. Keep/combine append new revisions on top of the cloud revision (restoring first if the cloud copy was deleted), so cloud history is untouched and no choice is automatic. Implemented in `CloudVault.resolveConflict`, both cloud stores (IndexedDB and the native SQLite `resolve` action) and `CloudControls`; no backend change. A resolution applies only to what was reviewed: inside the store's write transaction it is refused if the memory's pending local edits differ from the reviewed set (a newer edit from another window survives), and it is refused if the cloud revision changed since the review opened. Kept or combined text over the server's 256 KiB note limit is refused before anything changes.
