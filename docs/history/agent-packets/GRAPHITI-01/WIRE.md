# Knowledge wire v1

Transport: local HTTP service, POST /v1/snapshot, POST /v1/search, GET /v1/health. Authorization Bearer from RECALL_GRAPH_TOKEN (>=32 bytes), fixed native-configured loopback base URL RECALL_GRAPH_URL (default http://127.0.0.1:8766). Native only. Python bind loopback, reject cross-origin. No private content logs.

Snapshot request: {version:1, scope:string UUID, sources:[{id:string UUID,revision:positive integer,source_sha256:64hex,note_sha256:64hex,text:string (<=256KiB),source_name:string,note_path:string,captured_at:string,updated_at:string}], eligible_ids:[UUID], suppressed_facts:[string], rebuild:boolean}. Native creates packet from vault.list, verified originals; excludes conflicts/missing/deleted. Scope native vault UUID. Entire snapshot max 16MiB/10000 sources. Queue only eligible IDs after native consent. Removal/ineligibility revokes graph results immediately. Rebuild explicit, not automatic retry. Response status {state:string,pending:integer,indexed:integer,failed:integer,message:string}. Scope records stored separately; snapshot is serialized with worker commit to avoid resurrection.

Search request: {version:1,scope:string,query:string<=4096,limit:integer<=50,include_history:boolean}. Empty query retrieves bounded relationship exploration. Response {status:status,relationships:[{id:string,source_id:string,revision:integer,source_sha256:string,note_sha256:string,source_name:string,note_path:string,quote:string,subject:string,subject_type:string,predicate:string,object:string,object_type:string,fact:string,valid_at:string|null,invalid_at:string|null,extracted_at:string,inferred:boolean,uncertainty:string,related_source_ids:string[]} ]}. All graph-derived facts remain inferred even when language sounds explicit. Exact evidence quote must exist in source text; no match -> omit. No name-only identity claim. Returned source revision current unless explicit historical mode (native initially rejects historical if not independently validated).

Knowledge native UI methods (optional LocalVault extensions): knowledgeStatus(expectedVaultId), knowledgeConsent(expectedVaultId,enabled,includeExisting), knowledgeSearch(expectedVaultId,query,includeHistory=false), knowledgeDismiss(expectedVaultId,factId), knowledgeRebuild(expectedVaultId). Native result search wire with status; errors become honest unavailable state while keyword Ask remains functional. Consent stored in vault journaled control file separate from Graphiti, version 1, future-only fence by source IDs, explicit includeExisting opt-in. Dismissals persist independent of graph and suppress after rebuild; correction uses existing note correct API + reindex current revision. Native methods reconcile snapshot before search, enabled future processing triggered by native list/capture refresh without holding vault mutex over network. All server result IDs/hash/quote/paths checked against vault before returning. Never accept webview-provided snapshot or graph query language.

## Mandatory architecture review amendments (override earlier shorthand)
- Snapshot includes generation (monotonic persisted native scope epoch) and processing_allowed:boolean. Native serializes knowledge requests per scope; snapshot epoch changes with source snapshot/consent/controls, never backward. Python rejects lower generations; every worker commit compares epoch. Disabled processing sends empty eligible_ids, fences retrieval and purges derived scope; no extraction or search model calls.
- Every relationship includes supports:[{source_id,revision,source_sha256,note_sha256,quote}]. Native checks ALL support refs against current eligible vault records; unknown/missing support suppresses fact. quote is exact Markdown text, not a claim of OCR/photo original transcription. Original SHA separately binds immutable bytes.
- Changed/deleted/ineligible sources cause immediate retrieval fence and automatic scoped Graphiti rebuild from current eligible sources; manual rebuild is an additional repair control, not required for correctness. Upstream remove_episode alone is unsafe for shared derived state.
- Graph processing consent explicitly describes configured extraction/embedding/reranking providers and sending notes/questions to those providers; local graph storage enablement never authorizes external model calls. Default disabled. UI explicit purpose choice plus native configuration; no automatic reuse of Jev/Claude capture consent.
- Current production only uses current evidence; include_history must abstain where retained provenance not independently available. Temporal edge invalid_at remains usable as inferred supersession, not verified history.

## Runtime provenance correction

Graphiti 0.30.2 does not give original note text to its separate edge-attribute extractor. Recall therefore does not ask the model to manufacture source quotes or IDs. Each returned edge must link only to episodes whose native-assigned name exactly matches `source_id:revision:note_sha256` in the current authorized snapshot. Every support is constructed from that bound source, using the complete bounded Markdown as supporting note context. This is an exact source excerpt, not a claim that the whole inferred relationship has been independently verified or that Graphiti identified a precise evidentiary span. Original bytes remain separately hash-bound. Unmapped episodes suppress the entire relationship.
