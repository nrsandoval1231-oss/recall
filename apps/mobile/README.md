# Monolith mobile (Expo / React Native, iPhone first)

This app is the preserved authenticated cloud pilot. Home opens natural-language Ask; Capture saves ordered photos durably before upload; Detail shows the source, machine reading, uncertainty and processing state, with retry where available; Settings contains the AI-processing consent. Ask returns cited answers or an honest ambiguity/insufficient-evidence result with matching sources. These are legacy cloud capabilities, not the no-sign-in product target or evidence of vault-backed memory.

The shared capture engine in `packages/sync` copies bytes into app-private storage, hashes and journals the ordered draft, recovers after restart and performs idempotent upload/finalization. Ask, Detail and Capture call the existing workspace-authorized API. Keep authentication, processing, retrieval and source-access behavior honest; do not remove existing private API authorization to approximate local-only use.

Native camera, import, SecureStore and filesystem behavior still requires installed iPhone acceptance. See [developer setup](../../docs/DEVELOPMENT.md), [acceptance evidence](../../docs/ACCEPTANCE.md) and [the current product target](../../docs/PRD.md). Historical RCL-001 and RCL-002 evidence applies only to its named synthetic/cloud candidate; it does not prove current cross-device vault integration or live handwriting quality.
