# Recall desktop (Tauri 2 + React, Windows first)

## Current continuation — automatic organization

REALIGN-01 and TEXT-01 have independent local acceptance in `.agent/REALIGN-01/COMPLETION.json` and `.agent/FINISH-02/TEXT-COMPLETION.json`. INTELLIGENCE-01 has independent bounded acceptance for grounded Ask over current vault evidence in `.agent/INTELLIGENCE-01/COMPLETION.json`. ORGANIZE-01 is the active candidate: after one remembered purpose-specific opt-in, future text and photo captures are automatically queued for useful Obsidian organization. Its current status is in the active `.agent/ORGANIZE-01.md` packet; implementation in progress is not acceptance. Ask uses a separate, default-disabled `vault_intelligence` permission and versioned excerpt-processing consent. Photo permission does not authorize Ask. No live activation or provider processing is implied.

Ask considers up to eight current eligible memories, with bounded excerpts and visible coverage limits. It preserves uncertainty, opens cited memories/originals, and suppresses answers after source or vault changes. Keyword search remains available locally; it is not an offline generated answer. Historical questions, automatic AI text organization, grounded cross-memory links, voice/files, phone transport and full real-device/live acceptance remain open.

The default experience is local-first: choose an Obsidian vault, type/paste a note or import a PNG/JPEG/WebP, retain its original and history, search locally, inspect evidence and correct the note. When this exact device is owner-connected for photo inference, a user may request Claude to read one saved photo after explicit cloud-processing confirmation. A completed reading is stored with provenance and rendered as an automatically organized v4 Obsidian note candidate (summary, transcription, source-local mentions/statements, suggestions, uncertainty and properties). It remains explicitly machine-proposed; a human transcription correction takes precedence over stale machine organization without verifying every extracted claim. Exact validation/review is recorded in `.agent/REALIGN-01/COMPLETION.json` when frozen. Natural-language Ask remains open.

Local capture, annotation, evidence and keyword search need no remote account. The native adapter owns selected-vault disk operations; the renderer cannot choose arbitrary paths. Browser preview cannot save a native vault. Lifecycle commands support same-folder stable-ID renames, explicit missing-note restore, retained logical removal/history and keyword rebuild. Logical removal is not physical deletion, secure purge or undelete. See [local vault evidence](../../docs/implementation/local-vault/README.md), [lifecycle evidence](../../docs/implementation/local-vault-lifecycle/README.md) and [photo-reading evidence](../../docs/implementation/claude-vault-reading/README.md).

Run from the repository root with `npm ci`, then `npm run tauri -w @recall/desktop -- dev`; Rust 1.89+ and Tauri prerequisites are required. See [developer instructions](../../docs/DEVELOPMENT.md#local-only-desktop-foundation). Installed Windows acceptance remains open. A prior unsigned PR11 artifact is historical evidence, not a current installer or acceptance claim.

The explicit `?mode=legacy-cloud` entry preserves the earlier authenticated cloud application, including its API, source verification, SQLite/offline sync, outbox, export and privacy contracts. It remains separate from the default local vault entry and is not removed by the local-first target.
