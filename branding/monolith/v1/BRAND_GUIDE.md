# MONOLITH · Brand Guide v1.0

**Tagline:** Your world. Connected.

## Frozen product design
Keep the approved smoky-glass desktop and mobile UI, black/gray surfaces, soft translucent graph nodes, restrained imagery, Sora headings, and Inter body/UI typography. This pack is not a UI redesign.

## Symbol
Geometric architectural capital **M** assembled from two angled ribbon-like vertical forms. The M must read clearly at small sizes. No crystal, rock, split/slit, or added circle. Metallic treatment is optional: the one-color mark must remain recognizable.

## Usage
Use the metallic mark in hero/onboarding materials; flat white mark in product navigation and at small sizes. Ensure empty space around the logo of at least 20% of symbol width. Do not stretch, rotate, glow excessively, or place on busy photography.

## Notes
This is a vector reconstruction of the approved geometric-M reference rather than pixel-exact tracing. Inspect side-by-side before swapping application assets. The name MONOLITH has not been legally cleared for trademark or domain availability.

## Asset scope
This repository branch currently contains the source SVG mark variations, app SVG, design tokens and guide. The locally generated brand-kit ZIP also contains raster PNG sizes and a visual preview, which are not included in this GitHub branch.
