## Objective and finish boundary

On installed Windows, a user presses **Record**, speaks a short note, presses **Stop**, and sees the recording durably saved in the selected Obsidian vault before any interpretation. A pinned local ASR runtime produces a visibly unreviewed transcript; Recall optionally organizes it after a remembered future-only audio-purpose choice, and later answers a question with a citation that opens the original recording. The user can correct transcript wording; current organization/search/Ask follows the correction while history retains the machine reading. No Markdown, taxonomy, command-line model setup, or per-note filing. An optional native **Import WAV** action may feed the same path, but cannot substitute for Record/Stop acceptance. Phone recording and broader formats remain open.

This is a local voice slice, not parent completion. Real installed recording, nonempty local transcription, original playback, correction, consented organization and grounded retrieval all belong in the same bounded result. A capture-only stub, fake-only ASR, or WAV-only importer is not acceptance.

## Product architecture after F0 PASS

The native Windows adapter owns microphone permission and an explicit Record/Stop gesture. Bound recording length, byte count and resource use; write the actual supported 16 kHz mono signed PCM16 RIFF/WAVE source into a protected staging file with a durable operation identity. On Stop, publish immutable `Recall/Sources/<id>.wav` create-only and commit one versioned vault event through the existing journal and writer fence **before** ASR. Report interruption, device denial, silence, model unavailable and uncertain completion truthfully; no phantom saved/transcribed state. Optional WAV import verifies a regular file and byte-level format rather than trusting extension or MIME. Unsupported M4A/MP3/WebM files get a clear explanation. Neither UI nor model receives a selected filesystem path; the binary runs with fixed arguments against narrow private paths.

New audio provenance must include exact original hash and length, duration, capture/import origin, safe imported name when applicable, ASR runtime full revision/binary hash, model SHA-256, output hash, transcript status and processing attempt. Choose the next format version after the accepted R7A v8 format, retaining v1-v8 event and Markdown bytes and older-writer refusal. A create-only intent, source hash check and authoritative receipt make duplicate operation IDs retry-safe. Resume the same saved operation after a crash; changed source/vault/name or ambiguous process effect is a conflict/`UNKNOWN`, never a second capture or a silent overwrite. ASR is an optional derived operation after source save and has no authority over vault paths, identity, consent or citations.

The current `AnthropicProvider` and organization contract have image/text/Ask but no audio transcription. ASR output is **machine transcription**, not the exact human text used by TEXT-01 and R7A. Validate bounded UTF-8, timestamps/segments where emitted and exact model identity. Empty, corrupt, repetitive or unclear output remains failed/uncertain with the original still available. Model confidence does not make a fact verified. A human transcription correction is a distinct journaled revision, suppresses stale machine semantics and related links in current search/Ask, and leaves prior reading visible in history. A generated Obsidian note treats transcript as inert source content; direct supported human edits participate in conflict-safe reconciliation. Version any extraction/organization wire that cannot represent audio evidence truthfully, with examples and consuming tests in the same packet.

Use a **separate versioned audio-purpose consent** for future automatic semantic organization. Existing text/photo consent never enrolls audio. Record the decision/epoch at capture, save original first, dispatch only eligible new work, and revalidate current vault, source/revision/transcript hashes and consent before model call and proposal promotion. Later opt-in does not sweep the backlog. Claude receives only a bounded transcript and authorized current context as untrusted data; it supplies proposals, not verified claims or permissions. Oversize transcript, unavailable service or revoked consent leaves a useful local recording with honest status. Sent or ambiguous provider effects keep existing reservation/`UNKNOWN` handling and cannot be blindly retried.

Ask selects only eligible current or retained audio revisions under the existing vault authorization, correction and history rules. A material answer cites a source-backed transcript span or abstains; citation opens the verified original recording and indicates that an uncorrected transcript is machine-derived. Use segment time offsets if validated, otherwise cite the whole recording with that limitation. Never infer a speaker identity or certainty from a model label. No cross-workspace access, general authentication redesign, or autonomous action.
