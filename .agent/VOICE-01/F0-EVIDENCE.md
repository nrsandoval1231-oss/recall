# VOICE-01 F0 feasibility evidence

**Builder result: PASS with limits; independent review pending.** This closes only the isolated runtime and packaging feasibility question. It does not accept voice product behavior or the parent objective.

Pinned whisper.cpp v1.9.5 commit `d1be6fde11ac6e0407606b4e42fe72d34add8037` built as Windows x64 Release with MSVC 19.44 and CMake 3.31.6. The CPU backend selected AVX2/FMA/F16C/BMI2 on this host. The bundled multilingual `ggml-base.bin` from Hugging Face revision `5359861c739e955e79d9a303bcbc70fb988958b1` was verified at **147,951,465 bytes**, SHA-256 `60ed5bc3dd14eea856493d334349b405782ddcaf0028d4b5df4088345fba2efe` before execution. Final CLI SHA-256: `329c713c8b36eb8c367137d624b75ec57e17f8b3061fd823c59433abd5f76951`.

The final CLI returned the exact synthetic SAPI gold sentence in 1.265 s with sampled peak working set 317,554,688 bytes. A separate first run from the installed Tauri fixture returned the same sentence in 1.254 s at 317,116,416 bytes. Across 10 runs, measured elapsed time was 1.063–1.265 s and sampled peak working set was 215,683,072–317,554,688 bytes. These are single short, synthetic en-US runs on an Intel Core Ultra 5 225F with 10 logical processors and 32 GiB visible memory.

Quality is the main limit. Exact zero PCM16 silence produced the transcript `you` with exit 0. A 440 Hz tone produced `[Music]`; near-silence and low noise produced `[BLANK_AUDIO]`. Ten-percent and lower-gain variants of the known phrase all omitted “at three in the afternoon.” The malformed 17-byte WAV returned exit 11 and no transcript. A candidate RMS gate at or below 5 would reject the two generated zero/near-zero examples while preserving the tested low-gain speech, but this does not establish a real microphone VAD threshold; tones and everyday background noise remain unresolved. Do not treat machine transcript text as verified fact.

A minimal synthetic Tauri 2.12.2 app was built with local Tauri CLI 2.12.1 and NSIS 3.11, entirely under `%LOCALAPPDATA%\RecallBuildTools\voice-feasibility`. The voice config uses `externalBin: ["binaries/whisper-cli"]`, the x64 MSVC target suffix, four DLL resources mapped to the install root beside `whisper-cli.exe`, and model/license resources under `resources\`. The actual NSIS installer installed with exit 0. The installed model hash matched the pin and the installed sidecar transcribed the SAPI fixture without a model setup/download step. `dumpbin` showed the complete local DLL closure: `whisper-cli.exe → whisper.dll, ggml.dll`; `whisper.dll → ggml.dll, ggml-base.dll`; `ggml.dll → ggml-cpu.dll, ggml-base.dll`; `ggml-cpu.dll → ggml-base.dll, ADVAPI32.dll`; `ggml-base.dll → KERNEL32.dll`. The four local DLLs were installed beside the sidecar; no MSVC or OpenMP runtime DLL was required. Whisper.cpp, OpenAI Whisper, and the pinned model-card license material were retained in the fixture.

With the same minimal synthetic Tauri app and solid LZMA NSIS settings, the baseline installer was 1,915,548 bytes and the voice installer was 131,752,126 bytes: **+129,836,578 bytes (123.82 MiB)**. This is a measured fixture delta, not the final Recall installer size.
